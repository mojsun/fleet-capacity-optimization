# Fleet Capacity Optimization

**Operations analytics | Fleet scheduling | Decision support**

This repository contains a fleet capacity optimization project, organized around a Jupyter notebook and Excel workbooks used for analysis and scheduling. The project explores how fleet capacity and scheduling data can support operational planning and resource-allocation decisions.

## Repository structure

```text
fleet-capacity-optimization/
├── data/
│   ├── Optimized_Fleet_Schedule (1).xlsx
│   └── Project_Agnes.xlsx
├── notebook/
│   └── Fleet_Capacity_Optimization.ipynb
└── README.md
```

## Project files

- **`notebook/Fleet_Capacity_Optimization.ipynb`** — Jupyter notebook containing the project analysis and optimization workflow.
- **`data/Project_Agnes.xlsx`** — Project workbook used in the analysis.
- **`data/Optimized_Fleet_Schedule (1).xlsx`** — Workbook containing an optimized fleet schedule.

## How to explore the project

1. Open `notebook/Fleet_Capacity_Optimization.ipynb` on GitHub to review the analysis.
2. Download the repository if you want to work with the files locally.
3. Open the Excel workbooks in `data/` to inspect the project inputs and schedule.
4. To execute the notebook, open it in JupyterLab or Jupyter Notebook and install the packages imported in its first code cells.
